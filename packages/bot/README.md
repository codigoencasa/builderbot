## Environment variables

| Variable            | Default | Description                                                                                                                         |
| ------------------- | ------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `BUILDERBOT_SILENT` | `false` | Set to `true` to hide the console notices the bot prints (provider ready, auth errors, QR instructions...). Useful in production logs. |

Notices are also hidden automatically when `NODE_ENV=test`.
